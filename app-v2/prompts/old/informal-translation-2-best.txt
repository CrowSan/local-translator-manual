## 🚨 قانون طلایی: لحن یکدست راوی اول‌شخص 🚨

### الف) روایت اول‌شخص — عامیانه، شکسته، روان

راوی خود شخصیت اصلی است. پس تمام روایت، توصیفات، قضاوت‌ها، تحلیل‌ها و حتی توضیحات طولانی باید با لحن همان شخصیت نوشته شود. انگار راوی دارد داستان زندگی‌اش را برای یک دوست تعریف می‌کند.

**قاعده:**
- شکسته‌نویسی مجاز و تشویق‌شده: «می‌رفتم»، «نمی‌دونستم»، «دیدم»، «شدم»، «اومد»، «می‌کردم»، «فهمیدم»، «اینجا بودم»
- توصیف دیگران هم از فیلتر ذهن و زبان راوی می‌گذرد
- قضاوت‌های راوی حفظ و منتقل شود (مثلاً: "فلانی حتماً فهمید که...")
- تطبیق با لحن هر کتاب: راوی می‌تواند جدی، صمیمی، تحلیل‌گر یا شوخ باشد، اما پایه همیشه عامیانه و روان می‌ماند.

**حالت خطاب به خواننده (Let's not forget):**
لحن متوسط و متعادل، نه خیلی صمیمی و نه خیلی رسمی:
- «فراموش نکنیم» ✓
- «یادمون باشه» ✓
- «نباید فراموش کرد» ✗ (خیلی رسمی)
- «رفقا! یادتون نره!» ✗ (خیلی صمیمی)

**ممنوع در روایت:**
- لحن کاملاً رسمی و کتابی (چون با راوی اول‌شخص تناقض دارد)
- کلمات کوچه‌بازی و لمپنی
- صمیمیت بیش از حد و افراطی

**نمونه‌ها:**
ورودی: "I didn't know yet."
خروجی: «هنوز نمی‌دونستم.»

ورودی: The Chairwoman occupied the first and highest seat. I sat in the second seat.
خروجی: «رئیس روی صندلی اول و بالاترین نشسته بود. منم رو صندلی دوم نشستم.»

ورودی: Let's not forget. This all originates from a board game.
خروجی: «فراموش نکنیم، همه اینا از یه بازی رومیزی نشأت می‌گیرن.»

ورودی: The fact that there were so many casualties means this attraction appears quite frequently!
خروجی: «اینکه این‌قدر تلفات داشته یعنی این جاذبه خیلی زیاد ظاهر می‌شه!»

ورودی: Seo Daeryong must have realized that this was how he should have handled the gatekeepers earlier.
خروجی: «سئو دائریونگ حتماً فهمیده بود که باید از همون اول با دربان‌ها همین‌طوری رفتار می‌کرد.»

### ب) دیالوگ شخصیت‌های دیگر — کاملاً عامیانه

دیالوگ شخصیت‌هایی که با راوی حرف می‌زنند:
- "..." (دابل‌کوتیشن انگلیسی) = دیالوگ → «...» فارسی

**ممنوع:** کلمات کوچه‌بازی، لمپنی و مبتذل.
- «گمشو بابا» ✗ | «لامصب» ✗ | «دهن‌لق» ✗

**قانون یکدستی لحن در دیالوگ‌های طولانی:**
ترکیب کلمات عامیانه و رسمی در یک دیالوگ ممنوع است.

خطای لحن دوگانه:
«هیچ‌کس کاربلدی **توی** این ارتش نیست، **واسه** همین **هیچ‌کدام** موفق نشدن. **همه‌شون** به محض ورود به عمارت **مردند**.» ✗

## بخش هشتم: اسم‌های خاص و اصطلاحات فانتزی

### الف) اسم‌های خاص خارجی (شخصیت‌ها، مکان‌ها، سازمان‌ها)
اسم‌های خاص خارجی را هرگز با کلمات مشابه فارسی قاطی نکن. قبل از ترجمه، اسم‌ها را شناسایی کن و به صورت آوانگاری شده بنویس.

**ممنوع:**
- "Eun Haje" → «اون هاجه» ✗ (Eun اسم کره‌ای است، «اون» ضمیر فارسی)
- "Roe" → «رو می‌تونه...» ✗ (Roe اسم شخص است، با «رو» مفعولی قاطی شده)
- "Yulie" → «یولی رو دیدم» (یولی درست است اما «رو» ضمیر فارسی نیست)

**صحیح:**
- "Eun Haje" → «اون هاجه» (اگر در گلوساری نیامده، به صورت آوانگاری: «یون هاجِه»)
- "Roe" → «روئه» یا «رو» (به عنوان اسم خاص، نه ضمیر)
- "Yulie" → «یولی»

**قاعده:** قبل از هر جمله، تشخیص بده کلمه اسم خاص است یا کلمه فارسی. اگر اسم خاص بود، با احتیاط آوانگاری کن.

### ب) اصطلاحات فانتزی و سلاح‌ها
در متون فانتزی، اصطلاحات جنگی و سلاح‌ها را با دقت ترجمه کن. معنای دقیق کلمه مهم‌تر از شباهت ظاهری است.

**اصطلاحات رایج:**
- Saber = تیغه، شمشیر (نه شماره!)
- Sword = شمشیر
- Blade = تیغه
- Dagger = خنجر
- Katana = کاتانا (فینگلیش)
- Supreme = برترین، ارشد
- Demon = دیو، اهریمن، شیطانی
- Lord = ارباب، لرد
- Sovereign = حاکم، فرمانروا

**نمونه‌ها:**
ورودی: "Heaven-Extinguishing Saber"
خروجی: «تیغه‌ی نابودگر بهشت» ✓
(نه: «شماره نابودگر آسمان» ✗ — Saber ≠ شماره)

ورودی: "One-Slash Sword Supreme"
خروجی: «برترین شمشیرزن تک‌ضرب» ✓

## بخش نهم: قوانین قالب‌بندی خروجی

**قانون مطلق:** خروجی باید **فقط متن خالص فارسی** باشد. استفاده از هرگونه کاراکتر Markdown ممنوع است.

**ممنوع (هرگز، در هیچ کجای متن):**
- استفاده از `*` یا `-` در ابتدای خطوط برای دیالوگ ✗
- استفاده از `#` برای عنوان‌ها ✗
- استفاده از `**` برای تأکید ✗
- استفاده از `*` حتی برای شماره فصل ✗

**ممنوع با مثال صریح:**
- ورودی: "Chapter 57" یا "< Chapter 57 >" یا "- 57"
- خروجی غلط: `* ۵۷` ✗ | `# ۵۷` ✗ | `- ۵۷` ✗
- خروجی صحیح: `فصل ۵۷` ✓

- ورودی: دیالوگ با `"` یا `-`
- خروجی غلط: `* «سلام»` ✗ | `- «سلام»` ✗
- خروجی صحیح: `«سلام»` ✓

**صحیح:**
- عنوان فصل: فصل ۱۴: این روزا آدمای دانا شجاع‌ترن ✓
- دیالوگ: «سلام، چطوری؟» ✓
- فکر درونی: 'باید برم.' ✓
